===============================================================
configurazione firestore
===================================================================

npm install firebase @angular/fire

aggiungere app.config.ts
e importarla nel main.ts

andare su 
https://console.cloud.google.com/home/dashboard?project=progect_id
https://console.cloud.google.com/apis/credentials

nell'area id oauth 2.0 recuperare il client id e sostituirlo in environment.ts  webClientId
!!! deve essere preso quello del webclient non android


andare all'indirizzo
https://console.cloud.google.com/auth/clients?project=vg-game-workflow-ui
e cliccare su webclient

in  Origini JavaScript autorizzate aggiungere
http://localhost
http://localhost:8100
https://vg-game-workflow-ui.firebaseapp.com

URI di reindirizzamento autorizzati 

https://vg-game-workflow-ui.firebaseapp.com/__/auth/handler
http://localhost:8100/login
http://localhost:4200/login

applicare le regole corrette a firestore

andare nella cartella android del progetto e lanciare il comando
./gradlew signingReport
per recuperare il certificate hash da inserire nella console di firebase sotto impostazioni generali del progetto
scaricare su firebase il file google-services.json e inserirlo nella cartella src/app del progetto angular

npm install @capgo/capacitor-social-login

modificare il file android/app/src/main/java/com/mberti/tec/vgGameWorkflowUi/MainActivity.java !!! fondamentale per il funzionamento del login con google
